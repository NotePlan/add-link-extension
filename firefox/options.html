Send URL to NotePlan Settings

Invalid URL: Must start with 'noteplan://'

By default, this extension will use the default callback URL of NotePlan, adding a todo item to the top of today's Daily Note. However, if you're using Jonathan Clark's QuickCapture plugin, you can use alternative URLs for data entry (for example, to put the item under a specific heading): This assumes you have the plugin installed in NotePlan desktop of course.

For example:
noteplan://x-callback-url/runPlugin?pluginID=jgclark.QuickCapture&command=quick%20add%20checklist%20under%20heading&arg0=today&arg1=HEADING_NAME&arg2=
For example, you could modify arg0 and arg1, but leave arg2= at the end and paste it in the field above, and the URL and label will be added to the end behind arg2=.

Settings saved!
